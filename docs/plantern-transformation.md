# 路灯花变身机制

游戏 1.2.2 中，路灯花在 `Plant.PlantInitialize` 初始化时有 5% 概率进入变身流程：状态设为 `PlanternHenshinBegin`，倒计时设为 457；倒计时结束后转为永久的 `PlanternHenshinOver` 状态。

变身完成后有以下行为变化：

- 清雾半径由 4 格扩大到 18 格。
- 使场上所有罐子透明，不再受普通路灯花的一格距离限制。
- 使场上所有女忍者僵尸显形，不再受普通路灯花的距离限制。

修改器的“路灯花必定变身”选项通过现有 RNG Hook，在路灯花初始化期间临时将 `RandomNumbers.NextNumber(100)` 固定为 0。这样会完整执行游戏原生变身分支，并在初始化结束后恢复原有 RNG 状态。
