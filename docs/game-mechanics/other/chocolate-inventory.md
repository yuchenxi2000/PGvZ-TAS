# 巧克力数量的存储与上限

本文依据当前支持的 PGvZ 1.3.0、1.3.1 反编译代码，记录 `Lawn.StoreItem.STORE_ITEM_CHOCOLATE` 的库存编码。

## 数量编码

巧克力位于 `PlayerInfo.mPurchases[26]`。游戏以 `1000` 为基值；花园按钮显示的实际数量为 `mPurchases[26] - 1000`。首次拾取时，若旧值低于 `1000`，游戏把它设为 `1001`；以后每拾取一块加一。使用巧克力时减一。

`ZenGarden.CanDropChocolate()` 在已购买蜗牛的前提下，要求实际数量小于 `999` 才允许继续掉落。因此**正常掉落的上限是 999 块**，对应存储值 `1999`。拾取已生成的巧克力和调试加值路径本身没有再次限幅，所以内部整数并非绝对限制在 `1999`。修改器“设置巧克力”按正常库存范围接受 `0..999`，写入 `1000 + 数量`；数量为 `0` 时仍保留已发现巧克力的状态。
