# 安装与故障排查

## 安装

PGvZ-TAS/PGvZTool v1.14.0 及以后版本要求 PGvZ 1.3.0 或更高版本，不再支持此前的游戏版本。
建议升级游戏至最新版，或从
[GitHub Releases](https://github.com/yuchenxi2000/PGvZ-TAS/releases) 下载旧版本修改器。

### PC

1. 退出游戏。如果修改过旧版修改器中的文件，请先自行备份修改内容。
2. 删除 mods 目录中的旧版 `pgvz/`、`pgvztool/`、`gui/`、`cheat-gui.py` 和 `cheat.py`，
   不要直接覆盖安装，以免新版已经移除的文件残留，或旧版顶层入口继续被游戏自动加载。
3. 将新版 `pgvz/`、`pgvztool/`、`gui/` 和 `cheat-gui.py` 复制到 mods 目录。
4. 启动游戏，浏览器打开 `http://localhost:58080`。

也可以直接运行 `cp-cheat-mods.bat` 自动完成第 2 至第 3 步。自动工具为避免擅自删除可能被
用户修改过的内容，只会删除旧版 `pgvz/`、`pgvztool/`、`gui/` 和 `cheat-gui.py`；旧版
`cheat.py` 会原地改名为 `cheat.py.disabled`。如果目标名称已存在，脚本会使用另一个以
`.disabled` 结尾的名称，避免覆盖先前保留的文件。脚本不会处理其他模组，并会先检查安装
包文件齐全，再开始清理旧版文件。

### 安卓

1. 退出游戏。如果修改过旧版修改器中的文件，请先自行备份修改内容。
2. 删除 mods 目录中的旧版 `pgvz/`、`pgvztool/`、`gui/`、`cheat-gui.py` 和 `cheat.py`。
3. 将新版 `pgvz/`、`pgvztool/`、`gui/` 和 `cheat-gui.py` 复制到 mods 目录。
4. 启动游戏，浏览器打开 `http://localhost:58080`。

### mods 目录位置

| 平台 | 路径 |
|---|---|
| PC | `C:\Users\{用户名}\AppData\Roaming\ZBC\PlantGirlsVsZombies\mods` |
| 安卓 | `/storage/emulated/0/Android/data/net.pvz.pgvz.zbcteam/files/mods` |

游戏启动时会在后台自动加载修改器。自动收集等默认功能可以直接在游戏里使用，打开网页后可以调整选项和执行操作。

## 修改器使用

1. **放置植物/僵尸/物品**：先在网页中选择类型和属性，再点击对应按钮放置
2. **轻松放置**：先开启轻松放置；然后和上步相同，选择放置类型，接着轻松放置模式选择要放的是植物/僵尸/其他；最后在游戏内点击玉米饼（Taco）图标（在铲子右边），左键进行放置（可连续放置），右键退出轻松放置模式，手机端重新点击该图标退出轻松放置。选择传送门模式可移动传送门位置；选择放大模式后点击草坪格子，使用游戏内置的镜头放大功能，再次点击或按 Esc/返回恢复。进入放大选择时会退出轻松放置选中态，再次使用需重新点击玉米饼图标。
3. **TAS 工具**：勾选"启用 TAS"，右下角出现 Save/Undo/Redo/Adv 四个按钮和帧计数器，详见 [tas.md](../internals/tas.md)
4. **自定义快捷键**：在 `user_config.json` 同级目录新建 `keybinds.txt`，详见 [keybinds.md](keybinds.md)
5. **地形**：打开“出怪与布阵”右侧的“地形”页，需要时点击“读取当前地形”，手动读取当前背景、6×9 格子地形与右侧的六行类型。格子与行类型共用“草地、裸地、泳池、高地、浅水”五种画笔；选择后点击格子或右侧行类型，也可拖动矩形批量设置，松开后完成草稿填色。“草地”对应格子的 `Grass` 和行类型的 `Normal`。背景和两组地形都在点击“实施修改”后才写入当时的当前关卡；背景变更会刷新图片。修改不会保存为持续开关或自动用于其他关卡；换关不自动读取，也不会因草稿来自上一关而报错，需要查看当前地形时手动读取即可。字段赋值不会重建出怪表、割草机或已有植物，机制见[场景与地形](../../game-mechanics/other/background-and-terrain.md)。

地形编辑器默认显示白天，前五行是草地且行类型为普通，第六行九格和行类型均为裸地；未进入关卡时也可先编辑。
进入关卡后点击“实施修改”应用草稿；若要查看现有地形，点击“读取当前地形”。
实施修改也会按新地形校正地面植物的位置，保留血量、攻击计时及睡眠状态；正在离地的
植物和保龄球植物跳过，已经发射的子弹不迁移。

## 故障排查

### 启动黑屏闪退（仅安卓）

安卓上，游戏在主线程加载 `mods/` 顶层模组可能拖慢启动。修改器只在这一步执行 `cheat-gui.py`，其余包等到游戏就绪后在后台加载。

如果同时装了多个模组，可以暂时移出其他顶层 `.py` 文件后重试。保留 `pgvz/`、`pgvztool/` 和 `gui/`。

### 网页打不开

- 确认游戏正在运行，且安装或替换文件后已经完全重启游戏。
- 确认地址是 `http://localhost:58080`，注意是 `http` 而不是 `https`，冒号是英文冒号。
- PC 用户打开和 mods 同级的 `user_config.json`，确保 `ironpython_enabled` 为 `true`；手机
  用户没有这个文件是正常的。
- 确认 mods 文件夹顶层存在且只存在一个作为入口使用的 `cheat-gui.py`；备份文件不要保留 `.py`
  扩展名，否则游戏也会加载它。
- Android 应使用同一台手机内的浏览器访问；PC 用户也应使用本机浏览器访问。
- Android 上可重新解压并复制，必要时更换文件管理器，排除解压或复制损坏。

仍然打不开时，按下方[使用调试入口](#使用调试入口)操作，重点查看 HTTP 状态。

### 网页能打开但显示连接失败/一直转圈

- 确认只打开了一个修改器页面。
- 检查防火墙、代理、VPN 或浏览器安全设置是否拦截本机 WebSocket。
- 8080 端口可能被占用。可依次尝试：
  `http://localhost:58080/?ws=ws://localhost:8081/Py`、
  `http://localhost:58080/?ws=ws://localhost:8082/Py`、
  `http://localhost:58080/?ws=ws://localhost:8083/Py`。游戏会从 8080 开始寻找可用端口。

仍然无法连接时，按下方[使用调试入口](#使用调试入口)操作，以诊断信息显示的 WebSocket
实际端口为准。

### 网页空白或内容缺失

- 检查 `gui` 文件夹内文件的完整性。完全退出游戏，删除 mods 中的旧 `gui` 目录，再从同一
  发布包重新复制；不要只覆盖旧目录。
- 刷新或重新打开网页。正式入口已禁用缓存，因此不需要保留或继续使用旧页面。

仍有内容缺失时，按下方[使用调试入口](#使用调试入口)操作，重点查看 `gui` 文件检查结果。

### 网页按钮没有效果

- 先确认网页显示“可操作”；首次初始化完成前暂时禁止使用。若提示“已发送，切回游戏后生效”，请切回
  游戏；手机或 PC 未开启后台运行时，已发送指令会等待游戏回到前台后执行。
- 安装或替换 `cheat-gui.py`、`pgvz/`、`pgvztool/` 后必须完全重启游戏；只刷新网页不会让
  游戏重新加载 Python 文件。
- 确认 `pgvz/` 和 `pgvztool/` 来自同一个发布包且文件完整。完全退出游戏，删除旧目录后
  重新复制，不要覆盖安装，以免缺失文件或残留旧文件。
- 查看网页中的执行结果；如果出现包导入异常，优先重新复制 `pgvz/` 和 `pgvztool/`。

仍然无效时，按下方[使用调试入口](#使用调试入口)操作，重点查看 `pgvz` 和 `pgvztool`
文件检查结果。若文件检查为 `OK`，请保留网页“执行结果”中的完整异常信息。

### 提示“另一个修改器页面已连接”

- 官方网页同时只允许一个页面控制游戏。后打开的页面会被拒绝，可以继续使用原页面，
  或在当前页面点击“接管控制权”。接管也需要游戏恢复运行后才能完成。
- 如果原页面已被关闭、被系统回收或找不到，直接点击“接管控制权”，然后继续使用当前页面。
- 不建议通过 `file://` 直接打开 `gui/index.html`，因为这种方式不会获得本地 HTTP 服务器提供的缓存控制响应头。

### 修改器显示的状态与游戏内不一致

- 游戏内置作弊菜单的“自动收集资源”“房主无敌”和“后台运行”会与网页同步。首次连接网页时，已在内置菜单操作过的这三个开关以游戏内的当前状态为准。
- 若其他选项显示不一致，检查是否同时在使用其他修改器、调试工具或内置菜单。各入口可能修改同一个游戏变量，后执行的修改会改变实际状态，界面也可能仍显示旧值。单客户端保护只约束官方网页。

### 自定义快捷键无效

- 修改 `keybinds.txt` 后需重启游戏，后台加载修改器时会读取新配置。
- 已适配中文等常见非英文输入法；如果当前系统或输入法仍然拦截快捷键，请切换到英文输入法后再试
- 完整配置格式和可用功能名见 [keybinds.md](keybinds.md)

### 使用调试入口

调试入口适合区分入口未加载、HTTP 绑定失败、WebSocket 实际端口异常和安装文件缺失。它
不会修复问题，也不应代替正式入口长期使用。

#### 使用方法

1. 完全退出游戏，备份 mods 目录中的正式 `cheat-gui.py`：移出目录或者修改后缀名。
2. 将发布包中的 `debug/cheat-gui.py` 复制到 mods 目录并覆盖正式入口。正式和调试
   `cheat-gui.py` 入口只能保留一个；备份文件应放到其他目录，或改成不以 `.py` 结尾。
3. 启动游戏。游戏资源加载完成并进入主界面时会显示诊断弹窗。
4. 弹窗显示 HTTP 状态、WebSocket 实际端口以及 `pgvz`、`pgvztool`、`gui` 文件检查结果。
   弹窗打开时也可以访问网页测试。
5. 同样的诊断信息也会写入 `mods/pgvztool-debug-report.txt`。正常情况下，弹窗和报告应当
   同时存在。
6. 记录诊断信息后退出游戏，按照诊断信息排查错误。
7. 错误排查完毕，修改器可正常使用后，恢复正式 `cheat-gui.py`。确认正式入口已经恢复后，
   可以删除 `pgvztool-debug-report.txt`；不要使用调试入口正式游玩。

#### 根据诊断信息处理

| 诊断信息 | 处理方法 |
|---|---|
| 没有弹窗，也没有 `pgvztool-debug-report.txt` | 调试入口没有执行。确认文件位于正确的 mods 目录、文件名为 `cheat-gui.py`，并重新复制调试脚本。PC 用户还应确认 `user_config.json` 中的 `ironpython_enabled` 为 `true`；手机用户没有这个文件是正常的。 |
| 弹窗和 `pgvztool-debug-report.txt` 只出现其中一个 | 调试入口发生内部错误。保留现有的弹窗内容或报告文件，并连同游戏版本、系统和设备信息提交给项目开发者。 |
| `HTTP 58080: OK`，但网页仍打不开 | HTTP 服务本身已启动。确认使用 `http://localhost:58080`；Android 要在同一手机或模拟器的浏览器中访问。随后检查防火墙、代理、VPN、浏览器安全设置和本机网络环境。 |
| `HTTP 58080: 失败（…）` | 根据括号内异常排查。端口占用时关闭其他游戏实例、本地服务和重复的 `.py` 入口后重启；权限或网络异常时检查安全软件和系统网络限制。 |
| `WebSocket 端口: N` | 用 `http://localhost:58080/?ws=ws://localhost:N/Py` 访问，其中 `N` 替换为显示的实际端口。仍失败时检查防火墙、代理、VPN 和浏览器 WebSocket 限制。 |
| `WebSocket: 读取失败（…）` | 先确认使用受支持的最新游戏版本并重新复制调试脚本。若仍出现，保留完整异常信息；这通常表示游戏内部类型或字段与调试入口不匹配，需要提交给项目维护者分析。 |
| `文件检查：OK` | 三个组件的关键文件均存在。若页面或按钮仍异常，恢复正式入口后重试，并保留网页“执行结果”中的完整异常；`OK` 不代表每个文件的内容一定未损坏。 |
| `pgvz` 或 `pgvztool` 目录/文件缺失 | 完全退出游戏，删除 mods 中对应旧目录，再从同一发布包完整复制；不要覆盖旧目录。两个包必须来自同一发布包。 |
| `gui` 目录/文件缺失或 `index.html` 读取失败 | 完全退出游戏，删除旧 `gui` 目录后从同一发布包完整复制。Android 上必要时重新解压或更换文件管理器。 |
