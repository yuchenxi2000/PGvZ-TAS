# 安装与故障排查

## 安装

发布包已经包含 Vue 和 Element Plus，网页可离线使用。
[发布下载](https://github.com/yuchenxi2000/PGvZ-TAS/releases) · [游戏版本声明](../../../pgvz/version.py)

### PC

1. 退出游戏。如果修改过旧版修改器中的文件，请先自行备份修改内容。
2. 升级时先移除 mods 目录中的旧版 `pgvz/`、`pgvztool/`、`gui/`、`cheat-gui.py` 和 `cheat.py`。
   需要保留的顶层脚本请移出 mods，或改成以 `.disabled` 结尾，避免游戏继续加载。
3. 将新版 `pgvz/`、`pgvztool/`、`gui/` 和 `cheat-gui.py` 复制到 mods 目录。
4. 启动游戏，浏览器打开 `http://localhost:58080`。

也可以直接运行 `cp-cheat-mods.bat` 自动完成第 2 至第 3 步。自动工具为避免擅自删除可能被
用户修改过的内容，只会删除旧版 `pgvz/`、`pgvztool/`、`gui/` 和 `cheat-gui.py`；旧版
`cheat.py` 会原地改名为 `cheat.py.disabled`。如果目标名称已存在，脚本会使用另一个以
`.disabled` 结尾的名称，避免覆盖先前保留的文件。脚本不会处理其他模组，并会先检查安装
包文件齐全，再开始清理旧版文件。

### 安卓

1. 退出游戏。如果修改过旧版修改器中的文件，请先自行备份修改内容。
2. 升级时先移除 mods 目录中的旧版 `pgvz/`、`pgvztool/`、`gui/`、`cheat-gui.py` 和 `cheat.py`。
3. 将新版 `pgvz/`、`pgvztool/`、`gui/` 和 `cheat-gui.py` 复制到 mods 目录。
4. 启动游戏，浏览器打开 `http://localhost:58080`。

### mods 目录位置

| 平台 | 路径 |
|---|---|
| PC | `C:\Users\{用户名}\AppData\Roaming\ZBC\PlantGirlsVsZombies\mods` |
| 安卓 | `/storage/emulated/0/Android/data/net.pvz.pgvz.zbcteam/files/mods` |

将 `{用户名}` 替换为 `C:\Users` 下当前 Windows 账户的文件夹名。`AppData` 默认隐藏，可将完整路径粘贴到文件资源管理器地址栏打开。

游戏启动后会在后台加载修改器。请在运行游戏的设备上打开 `http://localhost:58080`，等页眉显示「可操作」后使用普通功能。同一设备可以同时打开多个标签页或浏览器，后打开的页面会读取游戏当前状态，已连接的页面共享设置更新。

## 修改器使用

1. **放置植物、僵尸和物品。** 在「场地」页选择类型和属性，在「场地放置」或「场地移除」卡片点对应按钮。
2. **轻松放置。** 在「场地」页的「对象选择」卡片打开「启用轻松放置」，设置「轻松放置模式」和要放置的对象。进关后点击游戏里的玉米饼（Taco）图标。它通常在阳光栏和进度条之间，铲子和手套同时显示时可在菜单右侧找到。PC 左键放置、右键退出。安卓点按场地放置，再点玉米饼图标退出。选择传送门模式可移动传送门。使用放大模式时，点击草坪格子放大，再次点击或按 Esc／返回恢复。恢复后可以再次点击玉米饼图标进入轻松放置。
3. **TAS 工具。** 在「基础」页的「常用修改」中打开「启用 TAS」。进入支持的关卡后，游戏右下角会出现 Save、Undo、Redo、Adv 和帧计数器。 [TAS 使用说明](../internals/tas.md)
4. **自定义快捷键。** 在 `mods/` 的上一级目录新建 `keybinds.txt`，重启游戏应用。 [快捷键配置说明](keybinds.md)
5. **地形。** 在「地形」页点击「读取当前地形」，载入当前背景、6×9 格子与六行类型。格子和行类型共用草地、裸地、泳池、高地、浅水五种画笔。可以点选或拖动矩形编辑草稿，点击「实施修改」时写入当时的关卡。切换关卡后，如需查看新关卡的地形，请手动读取。 [场景与地形](../../game-mechanics/other/background-and-terrain.md)
6. **Python 调试。** 在「调试」页的「输入 Python 代码」卡片中输入代码并点击「发送代码」。如果游戏实际使用了其他端口，请修改「Python 调试端口」。结果显示在页面下方的「执行结果」。 [脚本编写指南](scripting.md)

地形编辑器默认显示白天，前五行是草地且行类型为普通，第六行九格和行类型均为裸地；未进入关卡时也可先编辑。
进入关卡后点击“实施修改”应用草稿；若要查看现有地形，点击“读取当前地形”。
背景变更会刷新图片。地形修改只应用于当前关卡，不会重建出怪表、割草机或已有植物。
实施修改也会按新地形校正地面植物的位置，保留血量、攻击计时及睡眠状态；正在离地的
植物和保龄球植物跳过，已经发射的子弹不迁移。

## 故障排查

### 启动黑屏闪退（仅安卓）

安卓上，游戏在主线程加载 `mods/` 顶层模组可能拖慢启动。正式入口 `cheat-gui.py` 在这一步只配置路径并启动后台线程。HTTP 服务在后台启动，修改器包等到游戏就绪后加载。

如果同时装了多个模组，可以暂时移出其他顶层 `.py` 文件后重试。请保留本修改器的 `cheat-gui.py`、`pgvz/`、`pgvztool/` 和 `gui/`。

### 网页打不开

- 确认游戏正在运行，且安装或替换文件后已经完全重启游戏。
- 确认地址是 `http://localhost:58080`，注意是 `http` 而不是 `https`，冒号是英文冒号。
- PC 上如果在 mods 同级的 `user_config.json` 中看到了 `"ironpython_enabled": false`，请将其改为 `true` 后重启游戏。未设置此项时，游戏默认启用 IronPython。
- 确认 mods 文件夹顶层存在且只存在一个作为入口使用的 `cheat-gui.py`；备份文件不要保留 `.py`
  扩展名，否则游戏也会加载它。
- Android 应使用同一台手机内的浏览器访问；PC 用户也应使用本机浏览器访问。
- Android 上可重新解压并复制，必要时更换文件管理器，排除解压或复制损坏。

仍然打不开时，按下方[使用调试入口](#使用调试入口)操作，重点查看 HTTP 状态。

### 网页一直初始化、重连或显示「连接错误」

- 显示「正在初始化修改器...」时，切回游戏并等它加载完成，再回网页。PC 未开启「后台运行」时，初始化也可能需要游戏回到前台。
- 显示「正在重连，3秒后重试...」时，确认游戏仍在运行。网页会自动尝试恢复连接。
- 显示「连接错误」时，查看页面下方的「执行结果」。如果有导入错误，请保留完整调用栈，再从同一发布包重新安装并重启游戏。
- 显示「当前游戏版本不受支持」时，核对页眉的游戏版本，并安装适用于该版本的发布包。
- 打开 `http://localhost:58080/api/status` 可检查后台加载结果。`ready: false` 表示仍在加载，`error` 非空时可查看具体错误。如果 `ready` 为 `true` 且 `error` 为 `null`，修改器已经加载，网页还需等游戏处理首次状态同步。遇到 404，请确认 `cheat-gui.py`、`pgvz/`、`pgvztool/` 和 `gui/` 来自同一发布包，并重启游戏。
- 如果页眉已显示「可操作」，只有「发送代码」后出现「无法连接游戏的 Python 调试端口」，请用调试入口确认端口，再填入「调试」页的「Python 调试端口」。 [诊断报告](#根据诊断信息处理)

### 网页空白或内容缺失

- 检查 `gui` 文件夹内文件的完整性。完全退出游戏，删除 mods 中的旧 `gui` 目录，再从同一
  发布包重新复制；不要只覆盖旧目录。
- 更新后刷新所有仍然打开的修改器标签页，或关闭后重新访问 `http://localhost:58080`。已经打开的旧页面会继续运行先前加载的代码。

仍有内容缺失时，按下方[使用调试入口](#使用调试入口)操作，重点查看 `gui` 文件检查结果。

### 网页按钮没有效果

- 先确认页眉显示「可操作」。如果「执行结果」显示「已发送，切回游戏后生效」，请切回游戏让主线程处理指令。显示「执行成功」时，游戏已返回结果。
- 「速度控制」显示「等待游戏执行」时，也请切回游戏。
- 如果页面报告部分指令的执行结果未确认，请先回游戏检查是否生效，再决定是否重发。
- 安装或替换 `cheat-gui.py`、`pgvz/`、`pgvztool/` 后必须完全重启游戏；只刷新网页不会让
  游戏重新加载 Python 文件。
- 确认 `pgvz/` 和 `pgvztool/` 来自同一个发布包且文件完整。完全退出游戏，删除旧目录后
  重新复制，不要覆盖安装，以免缺失文件或残留旧文件。
- 查看网页中的执行结果；如果出现包导入异常，优先重新复制 `pgvz/` 和 `pgvztool/`。

仍然无效时，按下方[使用调试入口](#使用调试入口)操作，重点查看 `pgvz` 和 `pgvztool`
文件检查结果。若文件检查为 `OK`，请保留网页“执行结果”中的完整异常信息。

### 修改器显示的状态与游戏内不一致

- 游戏内置作弊菜单的「自动收集资源」「房主无敌」和「后台运行」会同步到网页，网页上第一项显示为「自动收集」。首次连接网页时，已在内置菜单操作过的开关以游戏当前状态为准。
- 内置菜单和网页各有一个「无冷却种植」开关。两个开关修改不同的游戏状态，互不同步。内置菜单会刷新冷却中的卡片，仍按原规则扣除阳光。网页开关会跳过卡片冷却检查，普通卡槽种植也会免除阳光消耗。 [无冷却种植的具体差异](../../game-mechanics/other/built-in-cheat-menu.md#无冷却种植)
- 网页「关卡与显示」中的「全局速度」对应内置作弊菜单的速度显示。「关卡速度」只影响当前关卡的游戏逻辑。
- 若其他选项显示不一致，检查是否同时在使用其他修改器、调试工具或内置菜单。各入口可能修改同一个游戏变量，后执行的修改会改变实际状态，界面也可能仍显示旧值。

### 自定义快捷键无效

- 修改 `keybinds.txt` 后需重启游戏，后台加载修改器时会读取新配置。
- 已适配中文等常见非英文输入法；如果当前系统或输入法仍然拦截快捷键，请切换到英文输入法后再试
- 完整配置格式和可用功能名见 [keybinds.md](keybinds.md)

### 使用调试入口

调试入口适合区分入口未加载、HTTP 绑定失败、GUI API 加载失败和安装文件缺失，并报告原生 Python 调试端口。它
不会修复问题，也不应代替正式入口长期使用。

#### 使用方法

1. 完全退出游戏，备份 mods 目录中的正式 `cheat-gui.py`：移出目录或者修改后缀名。
2. 将发布包中的 `debug/cheat-gui.py` 复制到 mods 目录并覆盖正式入口。正式和调试
   `cheat-gui.py` 入口只能保留一个；备份文件应放到其他目录，或改成不以 `.py` 结尾。
3. 启动游戏。游戏资源加载完成并进入主界面时会显示诊断弹窗。
4. 弹窗显示 HTTP 状态、Python 调试端口以及 `pgvz`、`pgvztool`、`gui` 文件检查结果。
   弹窗打开时也可以访问网页测试。
5. 同样的诊断信息也会写入 `mods/pgvztool-debug-report.txt`。正常情况下，弹窗和报告应当
   同时存在。
6. 记录诊断信息后退出游戏，按照诊断信息排查错误。
7. 错误排查完毕，修改器可正常使用后，恢复正式 `cheat-gui.py`。确认正式入口已经恢复后，
   可以删除 `pgvztool-debug-report.txt`；不要使用调试入口正式游玩。

#### 根据诊断信息处理

| 诊断信息 | 处理方法 |
|---|---|
| 没有弹窗，也没有 `pgvztool-debug-report.txt` | 先确认调试脚本已复制到正确的 mods 目录，文件名为 `cheat-gui.py`。PC 上还要确认没有在 `user_config.json` 中关闭 `ironpython_enabled`。 |
| 弹窗和 `pgvztool-debug-report.txt` 只出现其中一个 | 调试入口发生内部错误。保留现有的弹窗内容或报告文件，并连同游戏版本、系统和设备信息提交给项目开发者。 |
| `HTTP 58080: OK`，但网页仍打不开 | HTTP 服务本身已启动。确认使用 `http://localhost:58080`；Android 要在同一手机或模拟器的浏览器中访问。随后检查防火墙、代理、VPN、浏览器安全设置和本机网络环境。 |
| `HTTP 58080: 失败（…）` | 根据括号内异常排查。端口占用时关闭其他游戏实例、本地服务和重复的 `.py` 入口后重启；权限或网络异常时检查安全软件和系统网络限制。 |
| `HTTP 58080: 仅静态文件，GUI API 加载失败（…）` | 重新复制同一发布包的 `pgvztool/`，再完全重启游戏。若仍失败，保留括号中的异常。 |
| `Python 调试端口: N` | 如果「发送代码」后显示「无法连接游戏的 Python 调试端口」，在「调试」页的「Python 调试端口」填入报告里的端口，再点击「发送代码」。 |
| `Python 调试端口: 读取失败（…）` | 如果需要 Python 调试，确认使用受支持的游戏版本并保留完整异常。 |
| `文件检查：OK` | 三个组件的关键文件均存在。若页面或按钮仍异常，恢复正式入口后重试，并保留网页“执行结果”中的完整异常；`OK` 不代表每个文件的内容一定未损坏。 |
| `pgvz` 或 `pgvztool` 目录/文件缺失 | 完全退出游戏，删除 mods 中对应旧目录，再从同一发布包完整复制；不要覆盖旧目录。两个包必须来自同一发布包。 |
| `gui` 目录/文件缺失或 `index.html` 读取失败 | 完全退出游戏，删除旧 `gui` 目录后从同一发布包完整复制。Android 上必要时重新解压或更换文件管理器。 |
