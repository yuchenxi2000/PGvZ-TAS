# PGvZ 与 PvZ 的异同

本文集中记录植物娘大战僵尸（PGvZ）与英文原版植物大战僵尸（PvZ）的内容和机制差异，
供自动操作脚本、修改器功能和游戏机制文档共同引用。

## 总体关系

PGvZ 是基于 PvZ 的社区改版。对于从原版继承的内容，两者的主要游戏机制基本一致；
原版玩家以及 PyVZ、AvZ 用户对 PvZ 的理解大多仍然适用。

PGvZ 主要增加了若干废案植物、僵尸、关卡，以及来自其他改版的内容。这些新增内容在
原版中没有直接对应项，应按 PGvZ 自身的实现理解。

## 相对英文原版的已知差异

| 内容 | PGvZ 的差异 |
|---|---|
| 屋顶玉米炮 | 修复了炮弹落点可能发生偏移的问题。 |
| 裂荚射手 | 修复了前后同时有敌人时，正面会射出两颗子弹的问题。 |
| 猫尾草 | 阳光消耗由 225 调整为 200。 |
| 路灯花 | 种下时有概率觉醒，觉醒后强度大幅提高；概率、状态和具体效果见[路灯花变身机制](plantern-transformation.md)。 |
| 机枪射手 | 僵尸近身时改用刀攻击，而不是继续射击。 |
| 钉耙/玫瑰刺客 | 钉耙娘化为玫瑰刺客（Rose），由单体伤害改为范围伤害，但仍是一次性道具。 |
| 魅惑菇 | 刚种下、仍在播放入场动画时不能魅惑僵尸，也不会因僵尸啃食而掉血。 |

## 对脚本编写的影响

除上表和 PGvZ 新增内容外，编写原版内容的自动操作时可以先按 PvZ 的既有机制理解，再
针对脚本使用的具体关卡和时机进行测试。

从 PyVZ、AvZ 迁移脚本时，原版植物和僵尸的处理逻辑通常可以保留；需要重点调整的是
框架调用方式、PGvZ 新增内容，以及上表中明确受机制变化影响的操作。

PGvZ-TAS 只支持项目声明的最新游戏版本。直接依赖游戏内部成员或具体时序的脚本，应以
当前支持版本的类型存根和反编译代码为准。
