# 调试入口

本目录中的 `cheat-gui.py` 仅用于排查网页修改器无法连接的问题。它会在游戏加载完成后显示
HTTP 服务结果、WebSocket 实际端口，以及 `pgvz`、`pgvztool`、`gui` 关键文件的检查结果，
帮助区分入口未加载、端口异常、网络拦截和安装文件缺失。

使用时，用本目录中的脚本替换游戏 `mods/cheat-gui.py` 并重启游戏（原文件应该移到其他地方或者修改后缀名）。HTTP 服务会先启动，
诊断弹窗会在游戏资源加载完成并进入主界面时出现；此时 HTTP 和 WebSocket 都已可用，可以直接打开
网页测试。同样的信息会写入 `mods/pgvztool-debug-report.txt`，正常情况下弹窗和报告应当
同时存在；两者都没有表示入口未成功执行，只出现其中一个表示内部错误，应将已有信息提交
给项目开发者。排查完成后请恢复发布包根目录中的正式 `cheat-gui.py`，不要使用调试入口
进行正式游玩。
